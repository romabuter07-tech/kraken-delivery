# kraken-delivery
## О проекте

#### Kraken-delivery - информационная система для заказа и доставки морепродуктов.
#### Система позволяет пользователям просматривать каталог продукции, оформлять заказы, выбирать способ доставки и оплаты. Особое внимание уделяется *конфиденциальности персональных данных и безопасности сделок*.
## Цель проекта
Создать удобную систему доставки морепродуктов которая предоставляет:
- каталог морепродуктов
- оформление заказов
- отслеживание доставки
- защиту персональных данных
- безопасную оплату через криптовалюту
- быстрое решение спорных вопросов через поддержку и систему гаранта.
---
## Основные возможности
### Для покупателя
1. Регистрация и авторизация
2. Просмотр каталога товаров
3. Поиск и фильтрация морепродуктов
4. Добавление заказа в корзину
5. Оформление заказа
6. Выбор способа доставки
7. Выбор способа оплаты
8. Просмотр истории заказов
9. Отслеживание статуса доставки
10. Связь с технической поддержкой на всех этапах доставки.

### Для продавца
1. Регистрация и авторизация
2. Добавление товаров в каталог
3. Редактирование карточек товаров
4. Управление остатками
5. Управление заказами
6. Изменение статуса заказа
7. Взаимодействие с покупателями
8. Обращение в поддержку продавцов
9. Участие в спорных ситуациях
10. Просмотр истории продаж
---
## Роли пользователей
| Роль | Назначение |
| --- | --- | 
| **Администратор** | Управление системой и обеспечение ее работы |
| **Покупатель** | Поиск и приобретение товаров |
| **Продавец** | Размещение товаров и обработка заказов |
| **Поддержка покупателя** | Помощь покупателям |
| **Поддержка продавца** | Помощь продавцам |
| **Гарант** | Контроль безопасности сделок и разрешение спорных ситуаций |
---
## Оплата
Система предполагает несколько способов оплаты:
- Банковская карта
- Электронный платежи (СБП)
- Криптовалюта
- Наличными курьеру

При оплате криптовалютой система фиксирует статус платежа и связывает его с заказом
